# Documentary edit

Audition the actual existing MP4 and note the matching shot IDs and narration windows. Keep a source for each changed claim. Find holds that repeat what the image already says and pauses that help the audience absorb a fact. Shorten or move the former and retain the latter.

Spot one picture action per clause. Keep speech edits at sentence boundaries and measure the chosen voice before locking cuts. A comparison should identify its baseline file and source intervals, show the same story beats in order, and state any repacing or narration change.

Deliver timecoded decisions, revised narration, and shot purposes to the compositor and quality reviewer. For the Titanic Intel comparison, the input and baseline intervals live in `storyboards/titanic-intel-cut.json`.
